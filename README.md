# PATRI-TECH — Sistema de Inventário Patrimonial
Projeto desenvolvido para o **Estudo Dirigido 008** do programa **Bolsa Futuro Digital / Softex**.

O sistema PATRI-TECH é uma aplicação em Django com API REST construída para gerenciar:
- Categorias de bens  
- Status patrimoniais  
- Unidades  
- Salas  
- Bens (com regras específicas e tombo padronizado)

O objetivo é aplicar conceitos de:
✔ Django  
✔ Django REST Framework  
✔ DRF Spectacular (Swagger)  
✔ Git + Git Flow  
✔ Organização de API  
✔ Boas práticas de modelagem

---

## 🚀 **Tecnologias Utilizadas**
- Python 3.12  
- Django 6  
- Django REST Framework  
- DRF Spectacular (Swagger)  
- SQLite (banco de desenvolvimento)
